# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code and facts rather than people, and don't harass anyone. Maintainers may remove, edit or reject contributions and comments that don't follow it, and may ban contributors for repeated or serious violations.

Report unacceptable behaviour privately to the maintainer, Tej Maddimsetty, through a GitHub direct contact or a private security advisory marked "Code of conduct". Reports are handled confidentially.
